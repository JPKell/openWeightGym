{{ doc_header('User guide', contents=[('chat', 'Chat'), ('collections', 'Collections'), ('workflows', 'Workflows'), ('voice', 'Voice and media'), ('tools', 'Tools'), ('api', 'API keys and address')]) }} {% call doc_section('Chat', 'chat') %}

Start a conversation, choose the model beside Send, and type your message. The selected model stays visible. A model may need to load or its compute node may need to wake before it can answer.

Open Options to change the system prompt, reasoning and sampling, add attachments, or compare two models in a new conversation. Saved conversation options carry into follow-ups. Enter sends on a desktop keyboard; Shift+Enter adds a line. On phones, Enter adds a line.

Use the conversation list to reopen, find, rename or delete your own conversations. On phones, open Menu to reach the list. Stop interrupts a reply; Ask again retries the latest prompt. If no models are available, ask your administrator to grant model access.

{% endcall %} {% call doc_section('Collections', 'collections') %}

Create a collection with a local embedding model and a sensitivity level. Upload UTF-8 text or a searchable PDF, then select Index. Wait for Ready before searching.

Ask a question and choose an answer model, or retrieve excerpts only. Review the cited sources: similarity is a retrieval score, not a guarantee that an answer is correct. Collections and their sources are private to their owner. Resetting the embedding space clears its vectors and requires indexing again.

{% endcall %} {% call doc_section('Workflows', 'workflows') %}

Create a workflow using a collection, research question, models and prompt versions. Start research, review its sources and accept the result. Then start and review the draft.

Accepted research remains available after a failed draft. Resume / retry creates another attempt. Existing runs keep their selected models and prompt versions; create a new workflow to change its configuration. Deleting a workflow also removes its saved outputs.

{% endcall %} {% call doc_section('Voice and media', 'voice') %}

If Voice is available to your account, open Voice, allow microphone access and start a conversation. Browser calls need HTTPS or localhost. Speak to interrupt a reply, use Mute to pause your microphone, and Hang up when finished. The desktop app is another way to call.

Image generation, Music, Sounds and Speech are under Chat. Choose an appropriate permitted model, enter your prompt and generate. Saved media stays in your library. Recording a voice call is optional; the call page tells you when audio will be retained.

{% endcall %} {% call doc_section('Tools', 'tools') %}

{% else %}

If no tools are available, ask your administrator to check the ToolLocker service, configured servers and your tool access.

{% endif %} {% endcall %} {% call doc_section('API keys and model API', 'api') %}

Open My account to create an API key. Copy it when shown; it cannot be displayed again. Give it to your client as its API key, and keep it private. Removing a key ends access for clients using that key.

The standard model API address on this front server is {{ api_base }}, for trusted LAN or VPN access. If your administrator configured a different host, port or HTTPS gateway, use that address instead.

Use an OpenAI-compatible client, choose an allowed model, and send the key as a Bearer token. The model list is GET /v1/models. Chat uses POST /v1/chat/completions. Your usual model permissions and usage limits apply to API requests.
