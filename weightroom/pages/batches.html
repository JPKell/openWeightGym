A batch is a set of requests that a program hands in to be answered later, and comes back for. It is written down, so it goes on where it was after compute was restarted, went to sleep or lost power. Its requests wait behind everyone who is asking live, one at a time, and compute stays awake until they are done. The files of a batch are kept for a while after it has ended, and then removed.

As with OpenAI's Batch API, at compute's own address and with your own key. A file holds one request to a line:

{"custom_id": "q1", "method": "POST", "url": "/v1/chat/completions", "body": {"model": "NAME", "messages": [{"role": "user", "content": "..."}]}}
curl COMPUTE/v1/files -H "Authorization: Bearer KEY" -F purpose=batch -F file=@requests.jsonl
curl COMPUTE/v1/batches -H "Authorization: Bearer KEY" -H "content-type: application/json" \
     -d '{"input_file_id": "FILE", "endpoint": "/v1/chat/completions", "completion_window": "24h"}'
curl COMPUTE/v1/batches/BATCH -H "Authorization: Bearer KEY"
curl COMPUTE/v1/files/OUTPUT_FILE/content -H "Authorization: Bearer KEY"
