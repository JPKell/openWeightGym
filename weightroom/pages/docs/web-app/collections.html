Create a collection with a local embedding model and a sensitivity level. Upload UTF-8 text or a searchable PDF, then select Index. Wait for Ready before searching.

The requested model can run on any eligible node hosting that exact name. Differently named copies are refused. A failed source shows the error reason and a request diagnostics link; View collection event log opens its related events.

{% endcall %} {% call doc_section('Ask and check the sources', 'collections-ask') %}

Ask a question and choose an answer model, or retrieve excerpts only. Review the cited sources: similarity is a retrieval score, not a guarantee that an answer is correct. Collections and their sources are private to their owner. Resetting the embedding space clears its vectors and requires indexing again.
