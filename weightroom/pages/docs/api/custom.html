Image extraction uses caller-private /owg/extraction-assets, /owg/extractions and /owg/extraction-presets on front. Upload one raster image, then submit its asset ID with a permitted vision/schema model and task; poll the returned status URL. Submit Idempotency-Key to prevent duplicate jobs. Review requires the current revision; exports support revision=original. Inference uses normal admission and accounting. /owg/extraction-tools/{tool} is reserved for signed caller-bound ToolLocker dispatch.

Benchmark submissions accept explicit targets: [{model, machine}] for quality and resource runs. Recurring schedules also accept machine; kind outstanding uses optional model_ids/benchmarks scopes and freezes one missing/stale pair per occurrence. Scoped schedule inspection/dispatch use X-Suite-Schedule and recheck the owner's permissions. Unknown node availability defers selection; accepted tasks retain their exact node and identity.

Every row inherits the Common headers where its listener supports them. “None” means no additional route-specific request header. Authorization is still required: account abilities, resource ownership, scoped tokens and machine signatures are enforced by each handler. Path placeholders describe parameters; :int and :path are route constraints, not literal URL text.

The broad inference proxy is described under OpenAI compatibility; it is not enumerated as implemented endpoints. /loadcoach/task is a durable batch line marker, not a separately registered HTTP route.

Listeners: Turnstile/model operations normally use front port 8442; MCP uses the configured ToolLocker listener (normally 8443). Spotter routes use the configured telemetry/control listener. Voice gateway browser/admin routes are private (normally 8446), desktop streaming uses 8447, and its public listener exposes only the telephone allowlist. Compute voice normally uses 8445: HTTP uses signed callers, while its audio socket and deletion use the per-session bearer token. Direct /adapter/v1/ routes belong to the configured plugin adapter listener and use its pairing key; these are internal management APIs, not general account-key endpoints. Front-internal /turnstile/accounts, /turnstile/pick, /turnstile/log, /turnstile/log-facts and /turnstile/power require machine signatures. /loadcoach/front-probes and its interrupt route are internal dispatch only and are refused on the public front path. Schedule dispatch uses its scoped grant. Worker file PUT uses the short-lived preparation token in the path.
