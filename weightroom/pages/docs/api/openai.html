Other OpenAI batch endpoint choices are not implemented. See the official Batch API for the upstream contract; openWeightGym's narrower list above is authoritative here.

The worker registers a broad POST /v1/{path} inference proxy. A backend may accept an additional POST with a model field; that is backend-dependent passthrough, not an openWeightGym implementation or a compatibility promise. Unknown requests need not return 404: model validation or an engine refusal can happen first. Hosted forwarding likewise does not implement OpenAI resources locally.
