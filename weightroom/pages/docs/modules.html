The console machine, front, runs WeightRoom, Turnstile, ToolLocker and, when it is used, the voice gateway. Each GPU or CPU worker runs LoadCoach and Spotter. On a single machine they all run side by side. Front owns accounts and retained history; workers own model files and their own runtime state.
