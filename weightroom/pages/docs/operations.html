Start with Installation: one installer sets up the console, a one-time pairing code adds each GPU node to it, and the owg command looks after an installation afterwards. Where things run says which programs belong on which machine, and Settings where their settings come from.

Once installed, superusers update every machine from System → Deploy, described in Deploying from front. System → Components shows what each machine has installed. Editing a checkout alone may not change a running installation.

For a failed reply, start at Logs → Requests, then follow its diagnostics, trace and system-log links. Status shows the queue and which models are loaded, Telemetry shows each machine's resources and Alerts lists incidents. A reading that is unavailable is not proof that something has recovered. Restarting a service can interrupt requests and calls under way.
