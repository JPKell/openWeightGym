Model settings or context changed †
Prefer a completed run for the current settings. Otherwise show the latest saved result with its recorded configuration and a settings-changed label. Results are retained; Queue outstanding benchmarks can submit the replacement run.

Keep the result visible with a rerun recommendation. Queue outstanding benchmarks includes it.
Benchmark version, implementation or server mode changed *
Older evidence is retained but queued again on request. Saved answers are still regraded without inference when only the grader changed.
Score formula changed
Recalculate scores from saved measurements and model metadata. No new benchmark run.
