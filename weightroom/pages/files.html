Storage keeps every model file; downloads go there. The cache and each compute node hold copies of some of them. On Storage, tick a box to copy a file to the cache or a node, or clear one to remove that copy, then apply the changes together. Set the folders in General settings; to keep one folder for both, give the cache and storage the same path.

Consolidate cache copies every file a model uses on any node from Storage into the cache. Clear cache verifies every cached file byte-for-byte against Storage before removing anything. Large libraries can take an hour or more; cleanup continues in the background and this page updates when it finishes.
