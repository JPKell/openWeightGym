Submit a JSONL file to the front’s OpenAI-compatible Batch API using your own API key. Each line contains one request.

Responses lines use /v1/responses with input instead of messages. They are stateless: omit stream and previous_response_id; store defaults to false. These lines may share a file with chat completions.
