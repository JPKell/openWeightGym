New files come down on Hugging Face or Civitai and appear in the file lists below. Saving a new model checks every selected destination, promotes storage files and copies its complete bundle to those nodes. Each model is created after its files pass verification. Which parts each model needs

Unqualified models reserve their assigned cards. Shared residency requires reproducible placement and full workflow memory measurements, plus 256 MiB sampling headroom and the node's configured card margin. Shared workflows pin sampler, scheduler and CFG; use an exclusive entry to change those per request. Existing work finishes before settings take effect.
