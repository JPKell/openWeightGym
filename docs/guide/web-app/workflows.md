# Workflows

## Run a workflow {#workflows}

[Open Workflows](/workflows) to choose a saved run beside its research and draft. Search or filter by stage, or select New workflow to choose a collection, question, models and prompt versions. Unsent plans stay in this tab while switching runs. Start research, review its sources and accept the result. Then explicitly start and review the draft.

## Retries and changes {#workflows-retry}

Accepted research remains available after a failed draft. Resume / retry creates another attempt. Existing runs keep their selected models and prompt versions; create a new workflow to change its configuration. Deleting a workflow also removes its saved outputs.
