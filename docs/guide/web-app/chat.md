# Chat

## Start a conversation {#chat}

[Start a conversation](/chat), choose the model beside Send, and type your message. The selected model stays visible. A model may need to load or its compute node may need to wake before it can answer.

## Options and keys {#chat-options}

Open Options to change the system prompt, reasoning and sampling, add attachments, or compare two models in a new conversation. Saved conversation options carry into follow-ups. Enter sends on a desktop keyboard; Shift+Enter adds a line. On phones, Enter adds a line.

## Your conversations {#chat-list}

The list to the left of the chat lets you start, reopen, find, rename or delete your own conversations. On smaller screens, open Chat options, or Menu on phones. Switch between Chat options and Main menu with the button at the top of that drawer. Stop interrupts a reply; Ask again retries the latest prompt. If no models are available, ask your administrator to grant model access.
