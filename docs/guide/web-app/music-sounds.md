# Music and sounds

Create music or sound effects with a permitted audio model, then compare the resulting takes.

## Do it

1. Open **Music** or **Sounds** and choose the offered **Music model** or **Sound model**.
2. Describe **Style** for music or **Sound** for an effect. Choose **Seconds**, **Takes** or **Variations**, and the supported **Mode**. Some models return a fixed minimum length; a take whose length differs from **Seconds** by half a second or more says so beside its details.
3. Select **Generate**, listen to a take, and use the library's ordering and filters to find it again.

## Options

| Control | Use |
|---|---|
| **Song idea → Write** | Ask a permitted chat model or role for writing help. Review the resulting style and lyrics. |
| **Lyrics** / **Instrumental** | Offered only when the model supports separate lyrics; Sounds omits these music controls. |
| **Source audio** / **Use selected take** | Supply source audio for an offered editing mode. |
| **Repaint from (s)** / **to (s)** | Select the section to repaint when supported. |
| **Seamless loop** | Crossfade the seam of a new sound so it repeats without a click. |
| **Seed** | Reuse a seed for comparable variations. |

## Limits and troubleshooting

Modes and length limits follow the selected model. A model that does not accept separate lyrics shows **Your prompt is the score**; describe the arrangement in **Style**. Drafts stay with the selected model while the page remains open. Temporary source audio requires a temporary job. Current sharing and owner checks apply to every retained take.
