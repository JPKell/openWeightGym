# Fingerprints

Read immutable file and configuration evidence for recorded model identities.

## Before you start

Use an account with [model management](/docs/system/abilities#ability-manage-models). Disabled platform services may hide media and download choices.

## Do it

1. Open **Fingerprints** and use search, filters, sorting and pagination to find a record.
2. Select a row for **At a glance**, or open the permanent record for full file hashes and settings evidence.
3. Use the offered copy/JSON export controls to retain the exact recorded evidence.

## Limits and troubleshooting

A fingerprint is a saved snapshot. A current file or model can differ from its historical record; changing a display name does not rewrite old evidence. On smaller screens, a row opens the full record. Each node keeps its own record of a fingerprint, so the same snapshot on three nodes is three rows, each marked with its node; a row, its preview and its record link open that node's copy, and a full fingerprint without a node lists every copy. Retain the recorded hashes and identities when comparing benchmark results.
