# Model catalogue

Find model copies and add a verified installation.

## Before you start

Use an account with [model management](/docs/system/abilities#ability-manage-models). Disabled platform services may hide media and download choices.

## Do it

1. Open **Models**. Choose a compute-node filter and model type, then search or sort the catalogue.
2. Expand a row to inspect its node copies. Select a name or node chip to open its configuration or media studio.
3. Open **Add model**, select destination nodes and the source file, then review engine, projector and context before selecting **Add model** below the fields. Image, video and audio setup use the same model-name field and action layout, with runtime-specific file and hardware controls.

## Limits and troubleshooting

Installation checks selected destinations before copying. Review each node's progress and failure reason; an interrupted or failed installation does not prove a usable model copy exists. A model's trained context describes its metadata, not the memory currently allocated to each request.
