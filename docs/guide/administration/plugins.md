# Plugins

Manage external agent instances and the model aliases they expose.

## Before you start

Use [plugin-management access](/docs/system/abilities#ability-front-manage-plugins). The [Plugin module guide](/docs/modules/plugins) owns installation, pairing and authoring instructions.

## Do it

1. Open **Plugins** and review each manifest's enabled/valid state and synchronized authorization time.
2. Select **Edit** for a valid plugin and review its instances, profiles and offered model aliases.
3. Save the selected instance settings and use its offered health controls. Follow **Adaptor activity** for retained outcomes.

## Limits and troubleshooting

**Invalid** manifests cannot be edited as working adapters. Instance ownership, account model permission and current authorization still apply to requests. Plugin model aliases do not bypass normal tool, sensitivity or spending policies. A persistent agent session is separate from a text-chat conversation.
