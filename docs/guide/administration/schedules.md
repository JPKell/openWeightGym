# Schedules

Create recurring node backups or benchmark work and review occurrences.

## Do it

1. Open **Schedules**, choose **＋ New schedule**, and select its function and target node/model scope.
2. Review local time, time zone, selected weekdays and the displayed next occurrences before **Create schedule** or **Save schedule**.
3. Inspect **Recent runs** and **Open work**. Use **Pause**, **Resume** or **Delete schedule** for ordinary saved schedules.

## Limits and troubleshooting

A scheduled occurrence rechecks its owner's current permissions. The built-in control-node backup row uses **Backup policy** under **Retention and privacy** rather than independent schedule editing. Missed-work behavior is explicit in the editor. Missing/outdated benchmark selection freezes an eligible pair per occurrence; unavailable evidence can defer selection.
