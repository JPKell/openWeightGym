# Telemetry

Inspect host sensors and retained resource history.

## Do it

1. Open **Telemetry** and choose the host or node view.
2. Review current sensor readings alongside their available history.
3. Follow the associated node or service link when investigation needs an administrative action.

## Limits and troubleshooting

An absent sensor reading is unknown, not zero. Missing history does not establish inactivity. Host physical identity and compute-node names can have different lifetimes; compare the recorded host and time range when investigating a change.
