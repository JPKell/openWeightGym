# Stored responses

Inspect retained Responses objects and their continuation chains.

## Do it

1. Open **Responses** and use its owner, model, status and text filters to find a record.
2. Open the record to inspect saved input/output, request links and previous/next chain links.
3. Use its JSON export for an authorized private copy; confirm deletion when removing a record.

## Limits and troubleshooting

Stored Responses and ordinary request records are separate stores. Current account identity and sensitivity clearance still apply. A request sent without storage has no stored Responses object; a missing or hidden ID does not reveal another owner's record. Quotas and retention are in the [Settings reference](/docs/operations/settings-reference).
