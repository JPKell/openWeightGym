# Event log

Follow a trace through chronological events or a compact table.

## Do it

1. Open **Event log** and search or use the account, model, node and time filters.
2. Select a trace to read its chronological timeline, or switch to the compact table.
3. Select an event to inspect metadata and its exact request, batch or task links; export the filtered CSV when needed.

## Options

Double-click or press Enter to inspect a compact row. Historical paging uses timestamps. Refresh preserves the selected event, scroll position and chosen view.

## Limits and troubleshooting

Counts and export remain permission-scoped. Trace/batch/task context is exact; similar text is not proof that two events belong to the same request. Retention can remove older events.
