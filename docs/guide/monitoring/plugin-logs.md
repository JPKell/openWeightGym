# Plugin logs

Inspect adapter activity, session outcomes and exact exported records.

## Do it

1. Open **Plugin logs** and filter the retained activity by the available plugin, instance, model or session fields.
2. Select a record for **Request details**.
3. Use **Filter session**, **Copy JSON**, **Download JSON** or the CSV export for the authorized records you need.

## Limits and troubleshooting

**Records** counts activity entries: a request can have more than one outcome. Only instances and activity visible to this account appear. A session identifier scopes retained adapter activity; it does not grant access to another owner's agent session.
