# What openWeightGym is

openWeightGym provides a web console and model API for running permitted models on compute nodes or through configured providers.

## Before you start

Sign in with the account supplied by your administrator. Your account determines which pages, models and tools appear.

## Do it

1. Use **Interact** for text, voice, images and audio.
2. Open **Docs** to search the guides available to your account.
3. Use **My account** for personal preferences and application keys.

A configured role can choose an eligible model for you. A compute node may need to load a model or wake before replying. A cloud model sends your request to its configured provider; check which model you select before sharing private material.
