# Your first chat

Start with a short text conversation using a model your account can access.

## Do it

1. Open **Interact → Text chat**. Select a model beside **Send**.
2. Type a message, such as “Explain what a model role is”, then select **Send**.
3. Read the response and send a follow-up. Reopen it later from **Your conversations**.

## Limits and troubleshooting

If no model is available, ask an administrator to check your model access and the installation. Loading or waking a compute node can delay the first response. Use **Stop** to interrupt a reply; confirm when prompted.
