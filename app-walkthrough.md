## Models / Dry fit

Choose one compute node, then search or filter its catalogue and tick the models to run together.
The adjacent table shows only selected models; catalogue and table scroll independently. LLM
contexts accept exact token counts or sliders. Lock contexts before **Fit unlocked contexts**
to keep them fixed. Audio/image models use their configured fixed envelope instead of tokens.

Review the combined memory estimate. Save 1–16 selected models under a name, then use **Preview**
before applying settings or requesting the complete set. **API example** shows the two calls for
that saved set on its own node. Selecting a set or tuning controls never loads it.

See the [named-set API and memory contract](docs/loadcoach.md#validated-model-setup-and-presets-c05-milestone-93)
for permissions, exact profiles, unknown memory, lease renewal/release, stale reviews and undo.
